01 · Context

The problem & my role.

ShopSync is a database-driven e-commerce system developed at Kennesaw State University. I led a five-person team through a four-month delivery, translating shared requirements into a coordinated application.

Team lead & application developer

My work combined team leadership, core customer workflows, normalized data models, and cloud deployment. The project used Java, JavaScript, HTML/CSS, MySQL, and AWS, with Git/GitHub supporting collaborative development.

02 · Process

How the work came together.

  1. 01

    Align the team around requirements

    Led the five-person team through the software development lifecycle, from requirements through implementation and testing. Coordinated Git/GitHub changes so individual contributions could come together as one application.

  2. 02

    Build the customer journey

    Developed product browsing, cart management, and checkout workflows. These features formed the application’s primary path from discovering a product to completing a purchase.

  3. 03

    Organize the application’s data

    Designed normalized SQL data models to improve the consistency of stored information and the reliability of retrieval. MySQL supplied the relational foundation for the database-driven application.

  4. 04

    Connect the cloud services

    Deployed services on AWS EC2, managed relational data through AWS RDS, automated tasks with AWS Lambda, and served assets from AWS S3.
