# Pouya Rezazadeh — Portfolio

This folder is ready for GitHub Pages. The site has no framework or build step.

## Publish on GitHub Pages

1. Create a new public GitHub repository, such as `portfolio`.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will display the public website URL after the first deployment finishes.

## Customize

- Edit page content in `index.html`.
- Change colors and layout in `style.css`.
- Adjust the typing roles and interactions in `script.js`.
- Replace `resume.pdf` whenever your résumé changes.
- Keep `og.png` to preserve the social sharing preview.
